# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within LazyLayers, please report it responsibly by contacting the maintainer or opening a private security advisory on GitHub.

Please provide:
- A description of the issue and potential impact
- Reproduction steps or proof of concept code
- Proposed fix if available

We will review and respond to reports promptly.
