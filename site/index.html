Laziness scales.

Local-speed caching
for distributed Node.js apps.

Start with an in-process LRU. Add Redis when you need a shared L2. Add Redis Pub/Sub, RabbitMQ, or NATS when instances need to stay in sync. LazyLayers handles lazy loading, duplicate-load collapse, stale fallback, fail-open caching, cross-instance invalidation, and compact Redis payloads behind one TypeScript API.

  • Load late. Nothing is cached until somebody asks for it.
  • Load once. Concurrent loads collapse to one loader per process. Add Redis distributed lock for cluster-wide stampede protection.
  • Load small. MessagePack with size-tiered LZ4/Zstd compression, with runtime-aware fallbacks.

Quickstart

Up and running in 30 seconds.

A small Promise-based API that grows from a simple LRU into a coordinated distributed cache.

cache.ts
import Redis from 'ioredis';
import { LazyLayersCache, RedisStore } from 'lazy-layers-cache';

// Multi-tier cache: Sub-0.1ms L1 in-memory LRU + shared Redis L2
const cache = new LazyLayersCache({
  ttlMs: 300_000,
  levels: {
    L1: {
      maxEntries: 25_000, // Maximum in-memory capacity with LRU eviction
      ttlMs: 60_000,      // Hot L1 memory TTL (1 min)
    },
    L2: {
      ttlMs: 300_000,     // Redis backing store TTL (5 mins)
    },
  },
  l2: new RedisStore(redis, { prefix: 'app:' }),
});

// getOrSet collapses concurrent callers into a single database query
const user = await cache.getOrSet(`user:${id}`, () =>
  db.users.findById(id)
);

interface UserProfile {
  id: string;
  name: string;
  plan: 'free' | 'pro';
}

// Bind one cache instance to a strongly-typed value schema.
const users = new LazyLayersCache<string, UserProfile>({ ttlMs: 60_000 });

const user = await users.get('user:1'); // user is UserProfile | undefined
Why LazyLayers

Every server keeps its own memory.
Without a bus, caches drift.

Without invalidation, another instance can continue serving its stale in-process L1 copy until that entry's TTL expires. With a healthy invalidation bus, the stale window collapses from minutes down to network propagation latency.

Production guarantees

Built for when dependencies
have a bad day.

A cache earns the word production by answering failure modes up front. Most of that work is deciding what happens when databases stall, Redis disconnects, or message buses reorder packets.

Coherence on the wire

Three events.
Only one carries a value.

del and pattern just say what to forget. set brings the newly loaded value with it, allowing peer instances to warm L1 directly without redundant database trips.

Per-key generations reject older del and set events, reducing stale resurrection under reordering. Read the consistency model →

Benchmarks

Spend CPU where bytes are expensive.

Redis payload size using each library's default storage format. BentoCache default measurement includes its CacheEntry metadata envelope ({ value, createdAt, logicalExpiration }) because that is written to Redis; LazyLayers manages metadata separately and stores compact binary values directly.

Wire encoding

One record. Every byte accounted for.

Most of a JSON document is punctuation and repeated key names. Binary MessagePack stores the entire record in fewer bytes than JSON spends on values alone.
