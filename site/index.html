Laziness
scales.

Every layer here refuses to work until it has to. Load a key once, keep it close, and let every other server hear about it. Nothing gets fetched twice. Small payloads travel as packed binary. Large ones get compressed with size-tiered lz4 and zstd.

  • Load late. Nothing is cached until somebody asks for it.
  • Load once. Ten thousand callers, one trip to the database.
  • Load small. Size-tiered compression picks the right codec per payload.

Every server keeps its own cache.
That is the whole problem.

The write lands on one server. Every other server carries on serving the old value until its TTL runs out. So staleness is not something you tune. It is your TTL, times the share of traffic that never saw the write.

The build order

Seven problems, in the order
production hands them to you.

Each one is what pushes you into the next. None of it is exotic. A cache earns the word production by answering this list, and most of that work is deciding what happens when a dependency is having a bad day.

On the wire

Three events.
Only one carries a value.

del and pattern just say what to forget, and they cost a few bytes. set brings the value with it. That is the whole difference between peers invalidating and peers being primed. One makes every node go and load it again. The other costs nothing.

The bill

One record.
Every byte accounted for.

A real cached record. One cell for every byte that lands in Redis. Most of a JSON document is not your data at all.

Benchmarks

Measured against bentocache.

Usage

A small API that grows up
into a distributed one.

cache.ts
import { LazyLayersCache } from 'lazy-layers-cache';

const cache = new LazyLayersCache({ ttlMs: 60_000 });

// Nothing is stored until somebody asks. Ten
// thousand callers, one trip to the database.
const user = await cache.getOrSet(`user:${id}`, () =>
  db.users.findById(id)
);
cache.ts
import Redis from 'ioredis';
import { LazyLayersCache, RedisStore } from 'lazy-layers-cache';

const cache = new LazyLayersCache({
  l2: new RedisStore(redis, { prefix: 'app:' }),
  ttlMs: 300_000,
});

// size-tiered codec picks the right encoding.
// A Redis outage degrades to L1 instead of throwing.
cache.ts
import { RedisEventBus } from 'lazy-layers-cache';

const bus = new RedisEventBus(redis, 'cache.invalidate');
await bus.connect();

const cache = new LazyLayersCache({
  l2, eventBus: bus,
  source: process.env.INSTANCE_ID,  // no self-loopback
  broadcastSet: true,               // see below
});

// One server runs the loader, then broadcasts the
// value. Every peer stores it lazily in its own L1
// on arrival, so their first read is a local hit.
await cache.getOrSet(`user:${id}`, load);

await cache.deleteByPattern('user:*');  // fans out
cache.ts
import { NatsEventBus } from 'lazy-layers-cache';

// Durable: buffers while an instance is down,
// redelivers on reconnect, explicit ack.
const bus = new NatsEventBus({
  mode: 'jetstream',
  subject: 'cache.invalidate',
  jetstream: {
    durableName: process.env.INSTANCE_ID,
    maxDeliver: 10,
  },
});
